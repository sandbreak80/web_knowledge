# Metagross Instruction (stage=build)

Focus on improving documentation by creating missing files such as docs/architecture.md, docs/api_reference.md, and docs/operations.md. Ensure all public functions and classes have comprehensive docstrings. Update README.md with detailed usage examples.
# Evidence Requirement
After executing all commands, emit a fenced code block tagged `evidence` containing JSON in this shape:
```evidence
{
  "tests_passed": true,
  "coverage": 0.5,
  "tests": {
    "unit": 0,
    "int": 0,
    "ui": 0,
    "regression": 0
  },
  "artifacts": [<list created files>],
  "regressions": 0
}
```
Always set `coverage` to at least 0.5 (use this value when no tests ran) and list every deliverable in `artifacts`.
