# Metagross Instruction (stage=validate)

Review the completed Phase 3 deliverables to ensure all core functionalities are implemented and working as expected. Verify that the test coverage is above the required threshold and that all tests are passing. Confirm that there are no outstanding blockers or issues before proceeding to the next phase.
# Evidence Requirement
After executing all commands, emit a fenced code block tagged `evidence` containing JSON in this shape:
```evidence
{
  "tests_passed": true,
  "coverage": 0.5,
  "tests": {
    "unit": 0,
    "int": 0,
    "ui": 0,
    "regression": 0
  },
  "artifacts": [<list created files>],
  "regressions": 0
}
```
Always set `coverage` to at least 0.5 (use this value when no tests ran) and list every deliverable in `artifacts`.
