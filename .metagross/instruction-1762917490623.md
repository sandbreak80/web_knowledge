# Metagross Instruction (stage=build)

Proceed with Phase 1: Validation Gate Verification. Execute the following tasks: 1. Run `docker compose build` and capture logs to `artifacts/docker-build.log`. 2. Run `make docker-lint` and capture logs to `artifacts/lint.log`. 3. Run `make docker-typecheck` and capture logs to `artifacts/typecheck.log`. 4. Run `make docker-test` and capture logs to `artifacts/test.log` and `artifacts/coverage.json`. 5. Verify all gates pass or document acceptable exceptions. 6. Create an evidence summary referencing all artifact logs.
# Evidence Requirement
After executing all commands, emit a fenced code block tagged `evidence` containing JSON in this shape:
```evidence
{
  "tests_passed": true,
  "coverage": 0.5,
  "tests": {
    "unit": 0,
    "int": 0,
    "ui": 0,
    "regression": 0
  },
  "artifacts": [<list created files>],
  "regressions": 0
}
```
Always set `coverage` to at least 0.5 (use this value when no tests ran) and list every deliverable in `artifacts`.
