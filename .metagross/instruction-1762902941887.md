Proceed with Phase 1: Project Scaffolding & Infrastructure. Focus on setting up the Docker environment, project structure, and configuration system as outlined in the development plan. # Evidence Requirement
After executing all commands, emit a fenced code block tagged `evidence` containing JSON in this shape:
```evidence
{
  "tests_passed": true,
  "coverage": 0.5,
  "tests": {
    "unit": 0,
    "int": 0,
    "ui": 0,
    "regression": 0
  },
  "artifacts": [<list created files>],
  "regressions": 0
}
```
Always set `coverage` to at least 0.5 (use this value when no tests ran) and list every deliverable in `artifacts`.
